What it is

Your list, your server, their surprise intact.

Make a list of things you would like to receive, share a link, and let friends and family reserve items without stepping on each other. The list owner sees that an item is reserved, never who reserved it — so gifts stay a surprise — and it all runs on infrastructure you own.

Key features

Built for the way gifting actually works.

Reserver anonymity

The owner sees that an item is reserved, never who reserved it, so gifts stay a surprise. Enforced server-side, not just hidden in the UI.

Group co-buying

For an expensive item, friends split the cost through an opt-in, two-sided email handshake — and see each other's contact only once both agree.

Reservation decay

Stale reservations check back with the reserver and free themselves if abandoned, so an item is never locked forever.

Event-dated lists

A list for a specific occasion auto-closes after its date; evergreen lists live forever.

Browser auto-add

Paste a product URL and Yaadegar drafts the item from the page's metadata, with a strict, SSRF-safe fetch.

API-first & multi-tenant

Every capability is a documented HTTP API (OpenAPI 3.1). One instance serves many people, each with their own subdomain or custom domain.
